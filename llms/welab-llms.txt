# WeLab

> WeLab is a Hong Kong-headquartered fintech group (founded 2013) operating consumer lending, digital banking
> and payments across Hong Kong, mainland China and Indonesia — WeLend, WeLab Digital, WeLab Pay, Bank Saqu, and
> WeLab Bank Limited, an HKMA-licensed virtual bank. WeLab Bank is the group's API-bearing entity: it runs an
> Open API programme under the Hong Kong Monetary Authority Open API Framework, exposed through a
> registered-third-party-service-provider developer portal and mutual-TLS API gateways. No anonymous
> machine-readable specification is published.

Generated by API Evangelist from the public WeLab surface on 2026-08-05. This is a third-party profile;
API Evangelist does not operate these APIs.

## APIs

- [WeLab Bank Open API](https://portal-sandbox.welab.bank/): Open API programme under the HKMA Open API
  Framework. Indexed catalogue covers account information — account balance, account status, account
  transaction. Portal access requires registration with WeLab Bank as a third-party service provider.
  Gateways: `https://api.welab.bank` (production) and `https://api-sandbox.welab.bank` (sandbox), both
  requiring a client certificate (mutual TLS).

## Access

- Authentication: mutual TLS at the gateway; an anonymous request to the sandbox gateway returns HTTP 400
  "No required SSL certificate was sent". Application-layer credentials are documented only inside the gated
  portal.
- No public OpenAPI, AsyncAPI, GraphQL, MCP server or A2A agent card was found on any WeLab host
  (probed 2026-08-05).
- No `/.well-known/security.txt`, `/.well-known/openid-configuration` or `/llms.txt` is published on
  www.welab.bank or www.welab.co (404, probed 2026-08-05).
